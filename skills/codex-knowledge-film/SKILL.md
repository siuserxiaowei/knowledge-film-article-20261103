# 知识短片工坊

把概念演成观众能认出的东西。交付可修改的 Remotion 工程、事实与分镜、声音来源、字幕和用户要求的预览或MP4。默认中文、1920×1080、30fps；题材、比例、时长、风格与是否配音服从用户选择。

## 资源与入口

本文件所在目录称为 `SKILL_DIR`，脚本不依赖作者电脑或旧作品。

- 新建项目：`python3 SKILL_DIR/scripts/new_film.py OUTPUT_DIR --example queue`；`attention`是另一示例。拒绝覆盖非空目录。
- 新题目/参考分析先读[讲解与分镜](references/directing.md)。
- 改文稿/组件时读[数据约定](references/film-contract.md)。
- 配音/声音导入时读[音频](references/audio.md)。
- 从整段声音切句或复核导入来源时，再读[切句审核与来源守卫](references/alignment-and-provenance.md)。
- 首次准备环境或交付时读[渲染与验证](references/render-and-verify.md)。
- 安装/分发时读[INSTALL.md](INSTALL.md)。

`assets/template`是能运行的起点，不会根据新标题自动生成新的内容。新知识点需要新分镜和专用SVG/React场景，不能把示例标题换成新题目就交片。

## 工作方式

1. **建立目标。** 从上下文确定观众要明白的一句话、资料和交付程度，信息足够就推进。用户要配音时默认Ming-3.0-tts-0.5B/灵小锋，可改音色。先跑无旁白原型时准确标明状态；用户要完全静音时同时设置audio.music=false。
2. **先讲清再画。** 给概念找可识别的生活对象与动作，记录事实来源，示意数字标示意。同步写 `content/facts.md` 和 `content/storyboard.md`；每句有对象、动作与因果。参考片用于分析构图、节奏和配色，文稿与画面重新设计，保留来源与许可，不搬原片画面、音轨、水印或独特镜头表达。
3. **新建或接入。** 新目录用脚手架；已有Remotion项目先读规则和Composition注册方式，再移植必要工具，不初始化覆盖已有作品。原生组件优先；Canvas兼容层可编辑范围如实说明。
4. **难镜头与短样片先行。** 所有动画由frame/fps驱动，固定随机性，字体加载后再测字/渲染。先完成最难概念和前约20–30秒，查看静帧与转场，至少两轮同点修改。一个场景可贯穿多句，提问、命名和结论允许停住。问题未解决就继续改。
5. **离线准备声音和时间轴。** 编辑 `content/film.json`，运行 `tools/prepare_film.py`；新片用实测声音确定镜头长度。先短样音再批量。服务报错/额度不足即停并保留缓存；不能在预览或逐帧渲染中调用模型。没有令牌时检查可用配置、公开演示或已授权登录；只有必要的登录验证才请用户协助，不默认把整套配置交给用户填写。
6. **检查并交付。** 运行 `npm run check`，在Studio预览、正反定位。长音频切片须完成当前最终行映射的审核；未审声音可准备预览，正式导出守卫拒绝未审、漏词、串句或失效的记录。用户要成片时 `npm run render`，再用 `scripts/verify_render.py` 检查编码MP4、抽帧、测响度。实际查看帧图并核对人声；可用现有ASR辅助转录，不把文件存在或契约测试通过当成内容核对。记录限制。

## 示例工程命令

在项目目录中，先检查Node、Python3、FFmpeg/FFprobe，然后：

```bash
npm ci
python3 tools/prepare_film.py --mode silent
npm run check
npm run studio
```

用户要求成片时：

```bash
npm run render
python3 SKILL_DIR/scripts/verify_render.py --project . --video out/film.mp4
```

由助手把 `SKILL_DIR`、`OUTPUT_DIR` 解析成实际目录。声音命令见音频参考；不能手改静音报告冒充配音。

## 保持的约束

- 文稿真源 `content/film.json`，时间轴由脚本生成；文稿或参数变化后重建。守卫拒绝旧specHash，失败状态不能继续导出旧音轨。
- 密钥、Cookie、参考真人声音不进源码、静态目录、日志、压缩包或缓存身份。正常任务授权不扩大为新建账户、购买额度或公开发布。
- 官方API、HF Space、导入音频分开记录。Space不支持的指令/语速不能声称应用；导入WAV不能仅凭配置称为Ming生成。
- 缓存包含后端、模型、音色/参考声音内容、文本和实际参数；长音频切片还记录整段来源、切分范围与审核依据，密钥除外。
- 切片校验比较原源指定区间的PCM与实际导入声音；审核记录绑定最终行序、台词、音频哈希与来源区间，修改后重新审核。ASR原文保留；同音替换须有依据，不能用文本总分、删词或全句替换掩盖首尾丢字。
- 用绝对时间统一换帧，不逐段向上取整；字幕使用实际口语稿，不强行挤压旁白进估计窗口。
- `custom`是待实现画面，不能通过最终导出守卫；新题目应实现并注册专用场景。
- 编码结果与Studio都要检查。本机捕获问题可用已提供的Headless Shell/非共享内存参数；预览用原生HTML音频，导出仍用Remotion媒体管线，不把本机故障当成普遍规律。

## 报告

给出工程与媒体路径、真实模型/音色/后端、核对过的声音和画面、成片参数与未验证项。静音样片、真实配音、已编码成片、已完成内容核对是四个不同状态。
